# WebSocket Connection Pool

Manage WebSocket connections với room-based broadcasting.

## Features
- Connection pooling
- Room-based messaging
- Idle connection cleanup
- Broadcast to specific rooms
- Connection statistics

## Run
\`\`\`bash
npm install ws @types/ws
npm run dev src/real-time/websocket-pool/index.ts
\`\`\`

## Test
Open `client.html` in multiple browser tabs và test room messaging.
